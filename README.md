# Альфа-Курс — ИИ-помощник для предпринимателей

Telegram-бот и веб-приложение для предпринимателей. Помогает разбираться с практическими вопросами бизнеса, находить материалы «Альфа-Курса» и не забывать о важных задачах и сроках.

## О проекте

Предпринимателю часто приходится самостоятельно искать информацию об учёте, налогах, маркетинге и продажах, отбирать полезные учебные материалы и следить за регулярными задачами. Проект объединяет эти сценарии в одном помощнике.

**Целевая аудитория:** начинающие и действующие предприниматели, а также те, кто планирует открыть своё дело.

**Основной сценарий:**
1. Пользователь начинает диалог с ботом.
2. Помощник уточняет контекст: стадию бизнеса, сферу деятельности, налоговый режим, опыт и цель.
3. Пользователь задаёт вопрос обычным языком или просит подобрать материалы.
4. Система ищет релевантные фрагменты базы знаний и материалы «Альфа-Курса».
5. ИИ формирует ответ по найденному контексту. Если надёжной информации недостаточно, помощник сообщает об этом, а не должен придумывать ответ.
6. Пользователь может создать разовое или повторяющееся напоминание и управлять им.

## Возможности

### ИИ-помощник
- Обработка вопросов на естественном русском языке.
- Определение намерения пользователя: вопрос, подбор материалов, напоминание, обновление профиля или обычное общение.
- Уточнение недостающей информации.
- Использование истории диалога и сохранённого профиля предпринимателя.
- Поиск по базе знаний с порогом релевантности.
- Отказ от неподтверждённого ответа, если база знаний не содержит достаточной информации.

### Персонализация
- Сохранение стадии бизнеса: идея, запуск, действующий бизнес или развитие.
- Сохранение сферы деятельности, налогового режима, опыта и цели.
- Учёт профиля при подготовке ответов и ранжировании материалов.

### Материалы
- Поиск материалов по теме запроса.
- Ранжирование результатов по релевантности и профилю.
- Удаление дубликатов и отбрасывание слабых совпадений.
- Различение бесплатных и платных материалов; для платных материалов не показывается ссылка на бесплатный просмотр.

### Напоминания
- Создание напоминаний обычным текстом и через API Mini App.
- Разовые и повторяющиеся напоминания: ежедневно, еженедельно, ежемесячно, ежегодно или через заданное число дней.
- Просмотр, отключение, откладывание и изменение частоты поддерживаемых напоминаний.
- Учёт часового пояса пользователя.
- Примерные напоминания о налоговых сроках для поддерживаемых режимов. Даты необходимо сверять с официальной информацией ФНС.

### Telegram Mini App API
- Проверка подписи Telegram `initData` перед доступом к пользовательским API.
- Получение профиля и истории сообщений.
- Чат с ИИ-помощником.
- Получение и поиск материалов.
- Создание, просмотр, отключение и удаление напоминаний.
- Проверка состояния сервиса через `/health`.

## Архитектура

- `app/handlers.py` — команды, сообщения, кнопки и сценарии Telegram-бота.
- `app/dialog.py` — управление диалогом, ответы, рекомендации и напоминания.
- `app/analyze.py` — определение намерения, извлечение контекста и параметров запроса.
- `app/search.py` — поиск фрагментов базы знаний и материалов.
- `app/recs.py` — ранжирование и фильтрация рекомендаций.
- `app/reminders.py` — планирование и отправка напоминаний.
- `app/llm.py` — клиент OpenAI-совместимого API и генерация эмбеддингов.
- `app/db.py`, `app/schema.sql` — доступ к PostgreSQL и таблицы пользовательских данных.
- `app/api.py` — FastAPI, авторизация Telegram Mini App и HTTP endpoints.
- `app/main.py` — отдельная точка запуска Telegram-бота.
- `miniapp/` — исходный код React/TypeScript Mini App.

### Важное замечание по базе знаний

Пользовательские таблицы приложения создаются из `app/schema.sql`. Поиск знаний обращается к объектам схемы PostgreSQL `kb` (в частности, к функции `kb.search_chunks`) и каталогу материалов. Поэтому для полноценной работы ответов и рекомендаций в PostgreSQL должна быть загружена и подготовлена база знаний «Альфа-Курса». Одного запуска `app/schema.sql` для наполнения базы знаний недостаточно.

## Запуск локально

### Требования
- Python 3.11+
- Docker и Docker Compose
- Node.js и npm (для Mini App)
- Telegram Bot Token
- Доступ к PostgreSQL
- API-ключ выбранного OpenAI-совместимого провайдера
- Подготовленная база знаний «Альфа-Курса» в схеме `kb`

### 1. Настройка переменных окружения

Создайте файл `.env` в корне проекта на основе `.env.example`:

```env
TELEGRAM_TOKEN=токен_telegram_бота

LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_API_KEY=ваш_api_ключ
LLM_MODEL=llama-3.3-70b-versatile

POSTGRES_USER=alfa
POSTGRES_PASSWORD=замените_на_длинный_случайный_пароль
POSTGRES_DB=alfa

DEFAULT_TZ=Europe/Moscow
MINIAPP_ORIGINS=https://ваш-домен-miniapp
PLATFORM_URL=https://kurs.alfabank.ru/
```

Также проверьте остальные параметры в `.env.example`. Если используется отдельный API для эмбеддингов, задайте `EMBED_MODEL`, `EMBED_BASE_URL` и `EMBED_API_KEY`.

**Не добавляйте настоящий `.env`, токены и API-ключи в Git.** В репозитории должен находиться только шаблон `.env.example` без секретов.

### 2. Запуск PostgreSQL и API с Telegram-ботом

В текущей конфигурации `app/api.py` сам запускает Telegram polling и фоновый планировщик напоминаний. Поэтому для одного экземпляра бота используйте сервисы базы данных и API:

```bash
docker compose up --build -d db api
```

API будет доступен на порту `8081` хост-машины. Проверка:

```bash
curl http://localhost:8081/health
```

Ожидаемый ответ:

```json
{"ok": true, "service": "skilly-api"}
```

**Не запускайте одновременно сервисы Compose `bot` и `api` с одним Telegram-токеном:** оба процесса запускают polling, из-за чего они могут конфликтовать. Для отдельного запуска бота без Mini App API используйте:

```bash
docker compose up --build -d db bot
```

### 3. Запуск Mini App

```bash
cd miniapp
npm install
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

Mini App должен быть опубликован на HTTPS-домене, доступном Telegram. Укажите этот домен в `MINIAPP_ORIGINS` и настройках запуска Mini App. Адрес API должен быть доступен фронтенду.

## HTTP API

Основные маршруты:

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/health` | Проверка доступности API |
| GET | `/api/me` | Пользователь Telegram и профиль |
| GET | `/api/profile` | Получение профиля |
| PUT | `/api/profile` | Обновление профиля |
| POST | `/api/chat` | Сообщение ИИ-помощнику |
| GET | `/api/history` | История диалога |
| GET | `/api/materials` | Список и поиск материалов |
| POST | `/api/material-click` | Регистрация открытия материала |
| GET | `/api/reminders` | Список напоминаний |
| POST | `/api/reminders` | Создание напоминания |
| PATCH | `/api/reminders/{reminder_id}` | Изменение активности напоминания |
| DELETE | `/api/reminders/{reminder_id}` | Удаление напоминания |

Для пользовательских маршрутов требуется заголовок `X-Telegram-Init-Data` со значением `initData`, полученным из Telegram Mini App. API проверяет подпись и срок действия данных.

## Ограничения и важные условия

- Качество ответов зависит от полноты, актуальности и качества базы знаний.
- Если в базе нет подходящих подтверждённых фрагментов, помощник должен сообщить об отсутствии точного ответа.
- Налоговые напоминания носят информационный характер. Они не заменяют проверку актуальных сроков и требований на сайте ФНС.
- Для работы Telegram-интеграции необходим действующий токен бота.
- Для генерации ответов необходим доступ к настроенному OpenAI-совместимому API.
- Для поиска материалов и знаний необходимы корректно загруженные данные и объекты схемы `kb`.
- Mini App должен открываться через Telegram и использовать HTTPS; локальный адрес разработки сам по себе не является публичным адресом.
- Перед демонстрацией необходимо проверить связность Mini App с API, авторизацию через Telegram и доставку напоминаний.

## Что проверить перед демонстрацией

1. Бот отвечает на `/start` и обычное сообщение.
2. Помощник задаёт уточняющий вопрос, когда контекста недостаточно.
3. Ответ на вопрос действительно опирается на базу знаний.
4. На вопрос вне базы знаний помощник не выдумывает ответ.
5. Подбор материалов возвращает релевантные результаты и корректные ссылки.
6. Профиль предпринимателя сохраняется и учитывается в последующих запросах.
7. Создаются, отправляются и отключаются напоминания.
8. Учитывается часовой пояс пользователя.
9. Mini App открывается в Telegram, проходит проверку `initData` и получает данные от API.
10. После перезапуска контейнеров данные PostgreSQL сохраняются.

## Статус проекта

Проект содержит Telegram-бота, FastAPI для Mini App, React/TypeScript-клиент, интеграцию с PostgreSQL и ИИ-провайдером. Готовность к сдаче следует подтверждать проверкой развернутой версии по чек-листу выше. Наличие исходного кода само по себе не подтверждает, что все внешние интеграции и сценарии работают в демонстрационной среде.
